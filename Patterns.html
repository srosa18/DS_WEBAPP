3.2

Forms

Section title → Fields (persistent labels) → primary action. Closed domains (Country, Specialty) are Selects. Phone uses a mask. Validate on-blur and on submit; errors show a red border + message (text + icon). Submit goes to loading; success raises a Toast.

3.5

“Screen ready” checklist

A screen isn't done until every box is ticked.

  • Navigation in place (Tab Bar or App Bar back)
  • Loading state (Skeleton / Spinner)
  • Empty state
  • Error state with retry
  • Visible focus + logical keyboard order
  • AA contrast
  • Copy reviewed (tone + regulatory)
  • Zero loose values — tokens only
4

Accessibility (AA requirements)

The event's subject gives accessibility extra weight. These are requirements, not guidelines.

Contrast
Text ≥ 4.5:1 · large text & UI ≥ 3:1. (Hence the strong gradient on buttons.)
Visible focus
2px orange ring, offset 2px, on every interactive.
Persistent labels
Placeholder is never the only label (Field component).
Touch targets
≥ 44px on all controls.
Motion
Respects prefers-reduced-motion.
Not color alone
States carry text + icon. ARIA: aria-busy/live, role=alert, aria-required/invalid.
