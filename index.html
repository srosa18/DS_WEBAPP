Design System & Component Library

The complete UI kit for the
Summit Brazil 2026 webapp

A mobile-first, dark-only system for the BioMarin-funded medical event app, built for healthcare professionals. Reference platform: 440px. Everything below is token-driven — semantic over primitive, pill for actions & fields, 16px cards for content, separation by contrast (not shadow), and accessibility AA as a hard requirement.

PRINCIPLES
